# À quoi servent les workflows GitHub ?

Les workflows GitHub permettent d'automatiser les processus répétitifs du cycle de vie du logiciel. Au lieu de faire manuellement :

- l'installation des dépendances,
- l'exécution des tests,
- la génération de la documentation,
- le déploiement de l'application,

ont définis les actions dans un workflow qui s'exécute automatiquement.

ça permet donc de gagner du temps, d'éviter certaines erreurs humaines et de garantir que toutes les modifications passe par les mêmes étapes de validation.
