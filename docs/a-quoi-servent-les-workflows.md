# À quoi servent les workflows GitHub ?

Les workflows GitHub servent à automatiser les processus répétitifs du cycle de vie du logiciel. Au lieu de faire manuellement :

- l'installation des dépendances,
- l'exécution des tests,
- la génération de la documentation,
- le déploiement de l'application,

vous définissez ces actions dans un workflow qui s'exécute automatiquement.

Ils permettent ainsi de gagner du temps, d'éviter les erreurs humaines et de garantir que chaque modification passe par les mêmes étapes de validation.
